  <h2>📱 About the Project</h2>

  <p>
    Al-Waleed Student App is an educational mobile application designed to provide
    students with access to lessons, study materials, tests, exams, and live sessions.
  </p>

  <p>
    The application follows an Arabic RTL interface with a simple Light Mode design.
  </p>

  <h2>🚀 Implemented Features</h2>

  <h3>🔐 Authentication</h3>

  <ul>
    <li>Student Login</li>
    <li>Phone number authentication</li>
    <li>Password authentication</li>
    <li>Session handling</li>
    <li>Authentication error handling</li>
  </ul>

  <h3>📚 Lessons</h3>

  <ul>
    <li>View available lessons</li>
    <li>Lesson details</li>
    <li>Video content</li>
    <li>PDF lesson materials</li>
    <li>Lesson navigation</li>
  </ul>

  <h3>📝 Lesson Tests</h3>

  <ul>
    <li>Question-by-question navigation</li>
    <li>Multiple-choice questions</li>
    <li>Answer selection</li>
    <li>Progress tracking</li>
    <li>Test submission</li>
    <li>Test result</li>
    <li>Wrong answers review</li>
    <li>Retake test</li>
  </ul>

  <h3>🎥 Live Sessions</h3>

  <ul>
    <li>Display available live sessions</li>
    <li>Zoom / Google Meet support</li>
    <li>Copy live session link</li>
    <li>Open live session externally</li>
  </ul>
