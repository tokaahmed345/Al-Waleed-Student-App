  <h2>📱 About the Project</h2>

  <p>
    <strong>Al-Waleed Student App</strong> is an educational mobile application
    built with Flutter to provide students with access to their educational
    content, lessons, tests, study materials, exams, and live sessions.
  </p>

  <p>
    The application provides an Arabic <strong>RTL</strong> interface with a
    clean <strong>Light Mode</strong> design.
  </p>

  <p>
    The project includes multiple student flows covering authentication,
    lessons, lesson tests, live sessions, exams, profile management,
    and exam history.
  </p>
